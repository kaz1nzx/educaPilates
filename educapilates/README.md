# Educa Pilates — Next.js + React

Site institucional responsivo criado com Next.js, React e CSS puro.

## Rodar localmente

1. Abra o terminal nesta pasta.
2. Instale as dependências:

```bash
npm install
```

3. Rode o projeto:

```bash
npm run dev
```

4. Acesse http://localhost:3000

## Estrutura

- `app/page.js` — página principal e componentes React.
- `app/globals.css` — toda a identidade visual e responsividade.
- `app/layout.js` — metadata e layout global.
- `public/logo-educa-pilates.png` — logo enviada.
- `public/fachada.jpg` — foto da fachada enviada.

## Personalização

Os dados principais estão no começo de `app/page.js`:

- telefone/WhatsApp
- endereço
- link do Google Maps

O visual usa rosa, branco, vinho suave e tipografia editorial para combinar com a identidade da Educa Pilates.
